# Festival de Música

Proyecto web responsive para un festival de música.

## Tecnologías utilizadas

- HTML
- Sass
- JavaScript
- Gulp

## Características

- Diseño responsive
- Galería de imágenes
- Navegación entre secciones
- Compilación de Sass con Gulp
